# Noor Islamic Calendar

A Flutter Android starter project for Masum's Noor Islamic Calendar.

## Included in this starter
- Flutter Android project structure, including `android/`
- Bengali-first interface with English and Arabic labels
- Gregorian month calendar view
- Basic dashboard layout for prayer times, sunrise/sunset, and Ramadan information
- Creator credit screen showing **Masum**

## Important
This is a **starter prototype**, not a finished Islamic calendar or prayer-time app.
Prayer times, Hijri date conversion, Qibla direction, verified Bangladesh holiday data,
and reliable scheduled Adhan notifications still need to be implemented and tested.
Do not rely on placeholder prayer times for worship.

## Build
1. Install Flutter SDK on a computer or use a trusted cloud Flutter build service.
2. Run `flutter pub get`.
3. Run `flutter build apk --debug` for a test APK.
4. For release distribution, configure Android signing and test on real devices.
